# 更新链路修复

## 目标

修复 2026-10-07 审计 U01–U12，保证发布后的正确版本可下载，且只有完成校验、部署及必要的启动器维护后才能报告安装成功。

## 行为约束

- 在线安装与修复共用部署校验和活动标记提交规则；嵌套包必须解析到应用目录，任何缺文件或哈希错误都不得激活。
- 普通 Host 更新只能替换应用部署。启动器/根目录运行时变动必须交接完整维护安装，保留旧部署及回滚快照。
- 发布由成功的 Release 明确触发 Comparator；分通道、架构发布清单，公开 URL 校验通过后才更新 latest。
- 客户端先过滤通道与平台，再比较版本；基线不匹配选择 full，同版本镜像允许回退。
- 下载与安装串行执行；暂停/取消停止在途操作，过期任务不得回写状态；恢复已下载任务前检查暂存文件及清单。
- 完整安装使用当前安装根目录，等待并确认安装结果；需要退出时明确提示并通过现有应用生命周期退出。
- 在线首次安装准备所需 .NET 运行时；涉及系统权限的操作由安装流程执行。
- 延续现有稳定版默认值；通道界面按本轮用户选择落实。

## 验收

覆盖审计中的实际目录、包哈希、跨基线、架构/通道、取消竞态、恢复和回滚场景；构建宿主、安装器及发布工具，验证工作流结构与脚本。
