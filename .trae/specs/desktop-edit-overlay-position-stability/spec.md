# 桌面编辑预览位置稳定性

## 问题

拖动、调整和放置组件时，预览及候选落位框设置 Canvas 坐标后把 CompositionVisual.Offset 清零，导致渲染位置短暂跳向左上角第一格。重复更新同一个候选格子时，布局没有变化，错误位置还可能持续到下一次渲染属性同步。

## 要求

- 预览和候选框使用 Canvas 坐标定位。
- 清理位移动画时，渲染位置恢复为控件当前已完成布局的 Bounds.Position，不能恢复为原点。
- 下一次布局和渲染完成前保留已布局的位置，完成后使用新的 Canvas 位置。
- 连续更新同一个候选格子、移动指针和放置时都不得闪向第一格。
- 保留已有的缩放、透明度动画及网格吸附规则。

## 验证

使用真实 Avalonia CompositionVisual 验证重复更新和移动更新在渲染前后的坐标，并运行桌面编辑、网格吸附相关测试及桌面宿主构建。
