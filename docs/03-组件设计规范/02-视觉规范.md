# 视觉规范

本文讲组件视觉的**原则与用法**。**具体的资源键名与数值一律以 [设计 Token 与资源真源](00-设计token真源.md) 为准**——那份清单是从代码生成的，本文不再复制色值表。

> **本文已按代码更正**：旧版列出的十六进制色值表（`#0078D4`、`#F3F3F3` 等）在本项目里**不存在**——颜色由主题色系统运行时派生，没有固定色值表。
> 旧版列出的键名分两类：`CardBackgroundBrush`、`CardBackgroundSecondaryBrush`、`AccentBrush`、`AccentHoverBrush`、`AccentPressedBrush`、`SuccessBrush`、`WarningBrush`、`ErrorBrush`、`InfoBrush`、`CardBorderBrush`、`DividerBrush`、`TextBoxBackgroundBrush`、`TextBoxBorderBrush`、`DesktopBackgroundBrush`、`OverlayBrush`、`TooltipBackgroundBrush`、`FocusBorderBrush` **确实都不存在**（写了会静默失色）；而 `TextFillColorPrimaryBrush` 一族是 **FluentAvalonia 提供的真实键**，可以用——详见 [真源文档](00-设计token真源.md) 第 1.2 节。

最后核对：2026-11-14。

## 🎨 颜色

### 设计原则

- **语义化** —— 用"主文本/次文本/表面"这类语义键，而不是"深灰/浅灰"
- **主题自适应** —— 必须跟随亮/暗与材质色变化，绝不写死颜色
- **对比度** —— 文字必须可读（见下）
- **一致性** —— 只用真源里列出的键

### 怎么取色

颜色由 `ThemeColorContext` + `ColorMath` 从材质色/壁纸种子派生，经 `AdaptiveBrushFactory` 注册为 27 个 `Adaptive*` 资源键。

```xml
<!-- ✅ 正确：用真实存在的自适应键 -->
<Border Background="{DynamicResource AdaptiveSurfaceRaisedBrush}"
        BorderBrush="{DynamicResource AdaptiveGlassPanelBorderBrush}"
        BorderThickness="1">
  <StackPanel>
    <TextBlock Text="标题" Foreground="{DynamicResource AdaptiveTextPrimaryBrush}"/>
    <TextBlock Text="描述" Foreground="{DynamicResource AdaptiveTextSecondaryBrush}"/>
    <Button Content="操作" Background="{DynamicResource AdaptiveButtonBackgroundBrush}"/>
  </StackPanel>
</Border>
```

```xml
<!-- ❌ 错误一：写死颜色 → 不响应主题与材质色 -->
<Border Background="#FFFFFF"><TextBlock Foreground="#1C1C1C"/></Border>

<!-- ❌ 错误二：自造键名 → 取不到值，UI 静默失色，不报错也不警告 -->
<Border Background="{DynamicResource CardBackgroundBrush}"/>
```

**静默失色是本项目最常见的视觉缺陷形态**：键名写错不会编译报错、不会抛异常，只是那块 UI 变透明或变成兜底色。改完视觉一定肉眼过一遍亮/暗两档。

### C# 侧取色

唯一口径是 `AdaptiveTokens`，不要自己 `TryFindResource`：

```csharp
if (AdaptiveTokens.TryGet<IBrush>(this, ThemeResourceKeys.TextPrimaryBrush, out var brush))
{
    // 用 brush
}

var fallback = AdaptiveTokens.Brush(this, ThemeResourceKeys.SurfaceRaisedBrush, Brushes.Transparent);
```

### 对比度要求（WCAG 2.1）

| 文本类型 | AA | AAA | 本项目要求 |
|---|---|---|---|
| 正文（< 18pt） | ≥ 4.5:1 | ≥ 7:1 | ≥ 4.5:1 |
| 大号文本（≥ 18pt） | ≥ 3:1 | ≥ 4.5:1 | ≥ 3:1 |
| UI 组件与图形 | ≥ 3:1 | — | ≥ 3:1 |

自查工具：[WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)、[WhoCanUse](https://whocanuse.com/)。

注意：因为颜色是派生的，**对比度要在实际渲染结果上量**——不能靠阅读文档里的色值推算。

## 🔤 字体与排版

### 字体家族

| 键 | 值 | 说明 |
|---|---|---|
| `AppFontFamily` | **MiSans VF** | 内嵌字体，窗口级默认已绑定 |
| `AppFontFamilyJP` | MiSans JP | 日文 |
| `AppFontFamilyKR` | MiSans KR | 韩文 |

**不是** Microsoft YaHei UI 或 Segoe UI。旧版文档里写的系统字体方案已过期；`App.axaml` 里 `Window` 的 `FontFamily` 已默认指向 `AppFontFamily`，组件一般不需要自己设。

**没有 `DesignFontFamilyBase` / `DesignFontSize*` 这类 Token**——字号直接用 Avalonia 的 `FontSize` 值。

### 字号参考档位

以下是**约定**（不是资源 Token），用于保持组件之间的一致性：

| 用途 | 字号 | 字重 |
|---|---|---|
| 页面标题 | 28–32 | Bold |
| 区块标题 | 20–24 | SemiBold |
| 卡片标题 | 16–18 | SemiBold |
| 标准正文 | 14 | Regular |
| 辅助说明 | 12 | Regular |
| 核心数字（温度等） | 32–48 | Bold |

行高按字号的 1.4–1.6 倍取值；中文不必额外加字间距。

### 文本处理（Avalonia 原生能力）

```xml
<!-- 单行截断 -->
<TextBlock Text="很长的文字……" TextTrimming="CharacterEllipsis" MaxLines="1"/>

<!-- 多行换行 + 截断 -->
<TextBlock Text="很长的一段话" TextWrapping="Wrap" MaxLines="3" TextTrimming="CharacterEllipsis"/>

<!-- 对齐 -->
<TextBlock Text="居中" TextAlignment="Center"/>
```

## 🎭 图标

项目已引用两个图标库，**用它们，不要用字体 hack**：

| 库 | XML 命名空间 | 用法 |
|---|---|---|
| FluentIcons.Avalonia | `xmlns:fi="using:FluentIcons.Avalonia"` | `<fi:SymbolIcon Symbol="..."/>` |
| Material.Icons.Avalonia | `xmlns:mi="clr-namespace:Material.Icons.Avalonia;assembly=Material.Icons.Avalonia"` | `<mi:MaterialIcon Kind="..."/>` |

组件清单里的 `IconKey` 也走这套图标名（默认 `PuzzlePiece`）。

**尺寸档位**（约定）：12 / 16 / 20 / 24 / 32 / 48。

图标颜色用文字色键（`AdaptiveTextPrimaryBrush` 等）或 `AdaptiveAccentBrush`，不要写死。

图片图标：

```xml
<Image Source="avares://MyAirApp/Assets/icon.png" Width="24" Height="24"/>
```

## 🌑 阴影、圆角与边框

### 圆角

真值与两档差异见 [真源文档第 2 节](00-设计token真源.md)。要点：

- 桌面组件根容器**必须且仅能**用 `{DynamicResource DesignCornerRadiusComponent}`。
- 内部元素按层级用 `Sm` / `Md` / `Lg` 等 Token。
- **不要硬编码像素值**，也**不要**对圆角资源乘 `scale`。
- **不存在** `DesignCornerRadiusSmall` / `DesignCornerRadiusLarge` 这两个键。

```xml
<Border CornerRadius="{DynamicResource DesignCornerRadiusComponent}"/>
```

### 阴影

**没有全局阴影 Token**（旧版列的 `DesignShadowLevel1`-`4` 不存在）。需要阴影时：

1. 优先用已有的表面类（`glass-panel`、`surface-*`）——它们自带层级观感；
2. 需要额外阴影时写局部 `BoxShadow`，并在亮/暗两档都确认观感。

### 边框

| 粗细 | 用途 |
|---|---|
| 1px | 标准边框、分割线 |
| 2px | 选中 / 强调 |

```xml
<Border BorderBrush="{DynamicResource AdaptiveGlassPanelBorderBrush}"
        BorderThickness="1"
        CornerRadius="{DynamicResource DesignCornerRadiusComponent}"/>

<!-- 只留底边 -->
<Border BorderBrush="{DynamicResource AdaptiveGlassPanelBorderBrush}" BorderThickness="0,0,0,1"/>
```

## 🌈 透明与模糊

半透明通过表面类或 `AdaptiveGlass*Opacity` 一族键表达，**不要自己拼 `ExperimentalAcrylicMaterial`**——材质与模糊由宿主的材质色系统统一管理，自己拼一套会在切换材质时脱节。

| 观感 | 用哪个 |
|---|---|
| 玻璃面板 | `glass-panel` 类 |
| 半透明面板 / 强半透明 / 岛式 | `surface-translucent-panel` / `-strong` / `-island` |
| 纯色强表面 | `surface-solid-strong` |

## ✅ 视觉检查清单

**颜色**
- [ ] 全部用 `{DynamicResource Adaptive*}`，无硬编码颜色
- [ ] 键名逐字对照 [真源清单](00-设计token真源.md)，没有自造键
- [ ] 亮色、暗色、以及换材质色后都看过
- [ ] 文字对比度达标（在实渲染结果上量）

**排版**
- [ ] 没有自己设字体家族（沿用 `AppFontFamily`）
- [ ] 字号在约定档位内
- [ ] 长文本有截断或换行策略

**圆角与边框**
- [ ] 组件根容器用 `DesignCornerRadiusComponent`
- [ ] 内部元素用层级 Token，无硬编码像素
- [ ] 没有对圆角乘 `scale`

**图标**
- [ ] 用 FluentIcons / Material.Icons，不用字体 hack
- [ ] 尺寸在档位内，跟随文字色
