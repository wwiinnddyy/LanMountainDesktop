# 环境准备

## 需要什么

| 项 | 要求 |
|---|---|
| .NET SDK | 10.0（仓库 `global.json` 固定 `10.0.103`，`rollForward: latestFeature`） |
| 操作系统 | Windows 10+ / Linux / macOS |
| IDE | Visual Studio 2022+、Rider 或 VS Code + C# Dev Kit |
| 阑山桌面宿主 | 用于调试加载轻应用 |

验证 SDK：

```bash
dotnet --list-sdks
```

## 配置包源

`LanMountainDesktop.AirAppSdk` 发布在 **GitHub Packages**。
GitHub Packages 的 NuGet 源即使托管公开包，**还原时也必须提供凭据**，
所以第一步是配置认证，否则 `dotnet restore` 会直接 401。

### 1. 申请 token

在 GitHub 创建一个 classic Personal Access Token，勾选 `read:packages`。
只读包不需要其他权限。

### 2. 写入 NuGet.config

在轻应用项目目录放一份 `NuGet.config`：

```xml
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <packageSources>
    <clear />
    <add key="nuget.org" value="https://api.nuget.org/v3/index.json" />
    <add key="lanmountain" value="https://nuget.pkg.github.com/wwiinnddyy/index.json" />
  </packageSources>
  <packageSourceCredentials>
    <lanmountain>
      <add key="Username" value="你的GitHub用户名" />
      <add key="ClearTextPassword" value="你的PAT" />
    </lanmountain>
  </packageSourceCredentials>
</configuration>
```

> **不要把带 token 的 `NuGet.config` 提交到仓库。**
> 把它加入 `.gitignore`，或改用命令行注入：
>
> ```bash
> dotnet nuget add source https://nuget.pkg.github.com/wwiinnddyy/index.json \
>   --name lanmountain --username <用户名> --password <PAT> --store-password-in-clear-text
> ```

### 3. CI 中的配置

GitHub Actions 里用仓库 secret 注入。注意 `GITHUB_TOKEN` 只对**本仓库**的包有权限，
跨仓库读取需要一个带 `read:packages` 的 PAT：

```yaml
- name: Add LanMountain package source
  run: >
    dotnet nuget add source https://nuget.pkg.github.com/wwiinnddyy/index.json
    --name lanmountain
    --username ${{ github.actor }}
    --password ${{ secrets.LANMOUNTAIN_PACKAGES_TOKEN }}
    --store-password-in-clear-text
```

### 备选：本地源

不想配置 token 时，可以克隆宿主仓库自行打包：

```powershell
git clone https://github.com/wwiinnddyy/LanMountainDesktop.git
cd LanMountainDesktop
./scripts/Pack-AirAppPackages.ps1 -Configuration Release -OutputPath ./artifacts/nuget
```

然后把 `artifacts/nuget` 作为本地文件夹源加入 `NuGet.config`。

## 安装模板

```bash
dotnet new install LanMountainDesktop.AirAppTemplate
```

确认安装成功：

```bash
dotnet new list lmd-airapp
```

应当列出 `LanMountainDesktop AirApp / lmd-airapp / [C#]`。

## 工程结构

模板生成的工程只需要一个 `PackageReference`：

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net10.0</TargetFramework>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
    <Version>1.0.0</Version>
    <EnableDynamicLoading>true</EnableDynamicLoading>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="LanMountainDesktop.AirAppSdk" Version="1.0.0"
                      ExcludeAssets="runtime" PrivateAssets="all" />
  </ItemGroup>
</Project>
```

几个关键点：

- **不需要**显式引用 Avalonia。SDK 已经传递引用，版本由 SDK 决定，
  自己再钉一个不同版本的 Avalonia 会导致加载期类型冲突。
- `ExcludeAssets="runtime"` `PrivateAssets="all"`：SDK 程序集由宿主提供，
  不要打进 `.laapp`，否则会与宿主的同名程序集冲突。
- `EnableDynamicLoading` 让构建产出完整的 `.deps.json`，宿主强制要求它存在。
- **不需要**手写打包脚本。SDK 的 MSBuild targets 会在构建后自动产出
  `<AssemblyName>.<Version>.laapp`，并校验 `airapp.json` 与 `.deps.json`。

## 清单文件

`airapp.json` 放在项目根目录，构建时自动复制到输出并打进包。
这是宿主识别轻应用的唯一入口，字段以 SDK 的 `AirAppManifest` 为准：

```json
{
  "id": "Acme.WeatherAirApp",
  "name": "天气",
  "description": "显示实时天气的桌面组件",
  "author": "Acme",
  "version": "1.0.0",
  "apiVersion": "1.0.0",
  "entranceAssembly": "Acme.WeatherAirApp.dll",
  "sharedContracts": [],
  "runtime": { "mode": "in-proc" },
  "components": [
    { "id": "weather-now", "name": "实时天气", "defaultWidth": 2, "defaultHeight": 2 }
  ],
  "windows": [],
  "permissions": []
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 全局唯一。重复时宿主只加载第一个并记录冲突 |
| `name` | 是 | 显示名称 |
| `entranceAssembly` | 是 | 入口程序集文件名，重命名项目后必须同步 |
| `apiVersion` | 否 | 缺省取宿主当前 API 版本；填写时主版本必须匹配 |
| `description` / `author` / `version` | 否 | 元数据 |
| `sharedContracts` | 否 | 共享契约引用 |
| `runtime.mode` | 否 | 目前仅 `in-proc` 生效 |
| `components` / `windows` | 否 | 声明贡献内容，供市场展示 |
| `permissions` | 否 | 预留 |

`AirAppManifest` 不认识的字段会被忽略，不要指望 `icon`、`homepage`、
`minHostVersion` 之类的字段生效——这些属于**市场条目**，不属于清单。

## 安装位置

宿主从下面这个目录发现轻应用（`AppDataPathProvider.GetDataRoot()` 下）：

```
Windows: %LOCALAPPDATA%\LanMountainDesktop\Extensions\AirApps\
```

发现规则：

1. 递归扫描 `*.laapp` 包，读取包内的 `airapp.json`
2. 递归扫描散放的 `airapp.json`
3. `--dev-airapp` 指定的开发期覆盖

优先级 `--dev-airapp` > 散放清单 > `.laapp` 包，同 id 先到先得。
`.runtime` 子目录是解包暂存区，会被跳过。
