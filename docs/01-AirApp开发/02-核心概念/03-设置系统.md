# 设置系统

轻应用有两种提供设置界面的方式，都在 `Initialize` 中注册。

## 一、声明式设置节

描述需要哪些选项，由宿主统一渲染。适合大多数场景——不用写 UI，
外观自动与宿主一致，也自动跟随主题。

```csharp
services.AddAirAppSettingsSection(
    "weather",                      // 节标识
    "settings.weather.title",       // 标题本地化键
    section => section
        .AddToggle("auto_refresh", "settings.weather.autoRefresh",
            descriptionLocalizationKey: "settings.weather.autoRefreshDesc",
            defaultValue: true)
        .AddNumber("interval", "settings.weather.interval",
            defaultValue: 30, minimum: 5, maximum: 240)
        .AddText("api_key", "settings.weather.apiKey")
        .AddSelect("unit", "settings.weather.unit",
            choices: new[]
            {
                new AirAppSettingOptionChoice("metric", "settings.weather.metric"),
                new AirAppSettingOptionChoice("imperial", "settings.weather.imperial")
            },
            defaultValue: "metric")
        .AddPath("cache_dir", "settings.weather.cacheDir")
        .AddList("cities", "settings.weather.cities"),
    iconKey: "WeatherSunny",
    sortOrder: 10);
```

可用的选项类型：

| 方法 | 控件 | 关键参数 |
|---|---|---|
| `AddToggle` | 开关 | `defaultValue` |
| `AddText` | 文本框 | `defaultValue`、`validationPattern` |
| `AddNumber` | 数字 | `defaultValue`、`minimum`、`maximum` |
| `AddSelect` | 下拉 | `choices`、`defaultValue` |
| `AddPath` | 路径选择 | `defaultValue` |
| `AddList` | 字符串列表 | `defaultValue` |
| `AddOption` | 自定义定义 | 直接传 `AirAppSettingOptionDefinition` |

标题和描述传的都是**本地化键**，文案放在 `Localization/<语言>.json`。

## 二、自定义设置页

需要复杂交互或特定布局时，提供自己的 AXAML 视图：

```csharp
services.AddAirAppSettingsSection<WeatherSettingsPage>(
    "weather",
    "settings.weather.title",
    iconKey: "WeatherSunny",
    sortOrder: 10);
```

视图必须继承 `AirAppSettingsPageBase`（它本身是 `UserControl`）：

```csharp
public partial class WeatherSettingsPage : AirAppSettingsPageBase
{
    public WeatherSettingsPage()
    {
        InitializeComponent();
    }

    public override void OnNavigatedTo(object? parameter)
    {
        // 页面被导航到时刷新数据
    }
}
```

`AirAppSettingsPageBase` 提供的宿主能力：

| 成员 | 用途 |
|---|---|
| `HostContext` | 宿主上下文 |
| `OnNavigatedTo(parameter)` | 导航进入时的回调 |
| `OpenDrawer(content, title)` | 打开宿主抽屉面板承载子界面 |
| `CloseDrawer()` | 关闭抽屉 |
| `RequestRestart()` | 请求宿主重启以应用设置 |

写 AXAML 时遵循宿主的[视觉规范](../../03-组件设计规范/02-视觉规范.md)，
圆角一律用动态资源，不要硬编码像素值。

## 独立设置页

除了挂在轻应用节点下，也可以用特性声明一个独立设置页，由宿主反射发现：

```csharp
[AirAppSettingsPageInfo("acme.weather", "天气", AirAppSettingsPageCategory.AirApps)]
public partial class WeatherSettingsPage : AirAppSettingsPageBase
{
}
```

`AirAppSettingsPageInfoAttribute` 的可选项：
`TitleLocalizationKey`、`DescriptionLocalizationKey`、`IconKey`、`SelectedIconKey`、
`SortOrder`、`HideDefault`、`HidePageTitle`、`UseFullWidth`、`GroupId`、`Scope`。

分类取值：`General`、`Appearance`、`Components`、`AirApps`、`AirAppCatalog`、
`About`、`Dev`。轻应用一般用 `AirApps`。

## 读写设置

### 组件实例级

通过 `AirAppComponentContext.AirAppSettings`（`IAirAppSettingsService`）：

```csharp
var settings = context.AirAppSettings;
if (settings is not null)
{
    var section = settings.LoadComponentSection<WeatherSection>(
        context.ComponentId, context.PlacementId, "weather");

    section.City = "杭州";

    settings.SaveComponentSection(
        context.ComponentId, context.PlacementId, "weather", section);
}
```

`IAirAppSettingsService` 自动绑定到当前轻应用的 id，不会串到别的轻应用。

| 成员 | 说明 |
|---|---|
| `AirAppId` | 当前轻应用 id |
| `GetComponentAccessor(componentId, placementId)` | 取组件设置访问器 |
| `LoadComponentSection<T>(...)` | 读一节配置，`T` 需有无参构造 |
| `SaveComponentSection<T>(...)` | 写一节配置，可带变更键列表 |
| `DeleteComponentSection(...)` | 删一节配置 |

`placementId` 传具体值 = 每个放置实例独立配置；传 `null` = 组件级共享。

### 作用域

`AirAppSettingsScope` 定义配置的归属范围：

| 取值 | 含义 |
|---|---|
| `App` | 宿主应用级 |
| `Launcher` | 启动器级 |
| `AirApp` | 单个轻应用级 |
| `ComponentInstance` | 单个组件实例级 |

## 设置变更通知

设置变化通过消息总线广播，需要响应时订阅 `SettingsChangedEvent`：

```csharp
context.MessageBus.Subscribe<SettingsChangedEvent>(e =>
{
    // 判断是否是自己关心的节，再刷新
});
```

不要在每次渲染时轮询配置文件——落盘是异步的，轮询既慢又可能读到半截状态。
