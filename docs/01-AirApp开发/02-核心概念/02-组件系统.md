# 组件系统

桌面组件是轻应用最常见的贡献形态：一个 Avalonia `Control`，
由宿主渲染在桌面网格上，用户可以自由摆放和缩放。

## 注册

组件在 `Initialize` 中注册，两种写法等价：

```csharp
// 写法一：标识 + 配置回调（推荐，最常用）
services.AddAirAppComponent<WeatherWidget>(
    "weather-now",
    "实时天气",
    options =>
    {
        options.Description = "显示当前位置的天气";
        options.Category = "信息";
        options.IconKey = "WeatherSunny";
        options.MinWidthCells = 2;
        options.MinHeightCells = 2;
        options.ResizeMode = AirAppComponentResizeMode.Proportional;
    });

// 写法二：完整 options 对象
services.AddAirAppComponent<WeatherWidget>(new AirAppComponentOptions
{
    ComponentId = "weather-now",
    DisplayName = "实时天气",
    MinWidthCells = 2,
    MinHeightCells = 2
});
```

## AirAppComponentOptions

| 属性 | 默认值 | 说明 |
|---|---|---|
| `ComponentId` | 必填 | 组件标识，需在本轻应用内唯一 |
| `DisplayName` | 必填 | 组件库中显示的名称 |
| `IconKey` | `PuzzlePiece` | 图标键 |
| `Category` | `AirApps` | 组件库分组 |
| `MinWidthCells` | `2` | 最小宽度（网格单元） |
| `MinHeightCells` | `2` | 最小高度（网格单元） |
| `AllowDesktopPlacement` | `true` | 是否可放到桌面 |
| `AllowStatusBarPlacement` | `false` | 是否可放到状态栏 |
| `ResizeMode` | `Proportional` | `Proportional` 等比缩放 / `Free` 自由拉伸 |
| `DisplayNameLocalizationKey` | `null` | 名称的本地化键 |
| `Description` | `null` | 组件说明 |
| `DescriptionLocalizationKey` | `null` | 说明的本地化键 |
| `CornerRadiusPreset` | `Default` | 圆角预设 |
| `CornerRadiusResolver` | `null` | 自定义圆角解析 `(appearance, cellSize) => radius` |

**关于尺寸**：宿主没有独立的「默认尺寸」概念。组件放置时的尺寸是
`max(Min*Cells, 用户请求尺寸)`，所以 `MinWidthCells` / `MinHeightCells`
同时充当初始尺寸。想让组件默认 4×2，就把 Min 设成 4 和 2。

**关于圆角**：不要在组件根容器上硬编码圆角像素值。用 `CornerRadiusPreset`，
或从 `context.CornerRadiusTokens` / `context.Appearance.ResolveCornerRadius(...)` 取值，
这样全局圆角缩放设置才能作用到你的组件上。

## 控件

控件类型只要是 Avalonia `Control` 即可，不需要继承任何 SDK 基类。
构造函数由 `ActivatorUtilities` 调用，可注入：

- `AirAppComponentContext`
- 任何在 `Initialize` 里注册进 `IServiceCollection` 的服务

```csharp
public sealed class WeatherWidget : UserControl
{
    public WeatherWidget(AirAppComponentContext context, IWeatherService weather)
    {
        // context 描述这一个放置实例，weather 是本轻应用注册的服务
    }
}
```

宿主为**每个放置位置**创建一个独立实例。同一个组件被拖到桌面三次，
构造函数就被调用三次，`ComponentId` 相同而 `PlacementId` 不同。

## AirAppComponentContext

| 成员 | 说明 |
|---|---|
| `Manifest` | 本轻应用的清单 |
| `ComponentId` | 组件标识 |
| `PlacementId` | 本次放置的标识，区分同一组件的多个实例 |
| `CellSize` | 当前网格单元像素尺寸 |
| `AirAppDirectory` | 包目录，**只读**，升级会被覆盖 |
| `DataDirectory` | 数据目录，用户数据写这里 |
| `Services` | 本轻应用的服务容器 |
| `Properties` | 宿主属性，键见 `AirAppHostPropertyKeys` |
| `Appearance` | 主题上下文 |
| `CornerRadiusTokens` | 圆角令牌 |
| `AirAppSettings` | 组件实例级设置读写，可能为 `null` |
| `OpenWindowAsync(windowId)` | 打开本轻应用声明的窗口 |

## 主题适配

```csharp
public sealed class ThemedWidget : UserControl
{
    private readonly IAirAppAppearanceContext _appearance;

    public ThemedWidget(AirAppComponentContext context)
    {
        _appearance = context.Appearance;
        Apply(_appearance.Snapshot);
        _appearance.Changed += (_, e) => Apply(_appearance.Snapshot);
    }

    private void Apply(AirAppAppearanceSnapshot snapshot)
    {
        // snapshot 提供主题变体、强调色、色角色、材质表面等
    }
}
```

订阅了 `Changed` 就要在控件卸载时取消订阅，否则实例无法被回收。

## 组件实例设置

每个放置实例可以有自己的配置：

```csharp
var settings = context.AirAppSettings;
if (settings is not null)
{
    var section = settings.LoadComponentSection<WeatherSection>(
        context.ComponentId, context.PlacementId, "weather");

    section.City = "杭州";

    settings.SaveComponentSection(
        context.ComponentId, context.PlacementId, "weather", section);
}
```

`PlacementId` 参与键计算，所以桌面上两个天气组件可以配置成不同城市。
传 `null` 则是组件级共享配置。

## 组件编辑器

需要为组件提供专门的编辑界面时：

```csharp
services.AddAirAppComponentEditor<WeatherEditor>(
    "weather-now",
    preferredWidth: 720,
    preferredHeight: 540);
```

编辑器控件同样通过 `ActivatorUtilities` 创建，可注入
`AirAppComponentEditorContext`。

## 本地化

组件文案放 `Localization/<语言代码>.json`，随包一起分发：

```csharp
var localizer = AirAppLocalizer.Create(context);
var title = localizer.GetString("weather.title", "天气");
var tip = localizer.Format("weather.updated", "更新于 {0}", time);
```

`GetString` 的第二个参数是找不到键时的回退文案，所以缺翻译不会显示成空白或键名。
当前语言由宿主通过 `Properties` 传入。
