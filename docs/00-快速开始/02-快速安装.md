# 快速安装

本指南帮助你安装并首次运行阑山桌面。

## 安装方式

### 方式一：使用安装包（推荐）

从 [GitHub Releases](https://github.com/wwiinnddyy/LanMountainDesktop/releases) 下载：

| 产物 | 说明 |
|---|---|
| `LanMountainDesktop-Setup-{version}-x64.exe` | x64 安装包 |
| `LanMountainDesktop-Setup-{version}-x86.exe` | x86 安装包 |

安装包用 Inno Setup 打包，**默认需要管理员权限**（`PrivilegesRequired=admin`），安装到系统的程序文件目录。

安装完成后启动器会自动运行。

> **没有"便携版安装包"**。Release 里只有上面的 Setup exe 与载荷 zip（`files-windows-{arch}.zip`），不存在 `LanMountainDesktop-Portable-*.zip` 这种产物。

#### 首次启动（OOBE）

首次启动会走 OOBE：Splash 先显示，随后 OOBE 阶段临时隐藏 Splash 展示欢迎页，完成后恢复。OOBE 里会依次完成数据位置选择、宿主设置合并、Windows 自启动项、隐私同意；取消或保存失败会中止启动。

完成后写入标记 `{数据根}\Launcher\state\oobe-state.json`。该文件存在时后续启动不再显示 OOBE。

### 方式二：从载荷 zip 自行部署

没有现成的便携包，但可以自己拼：

```powershell
# 1) 下载载荷（release 里的 files-windows-x64.zip）
# 2) 解压到一个目录，得到 LanMountainDesktop.Launcher.exe、AirAppRuntime、app-{version}/ 等
Expand-Archive -Path files-windows-x64.zip -DestinationPath C:\LanMountainDesktop

# 3) 启动
C:\LanMountainDesktop\LanMountainDesktop.Launcher.exe
```

数据位置有两种模式（由 OOBE / 数据位置配置决定，之后也可迁移）：

- **系统位置**：`%LOCALAPPDATA%\LanMountainDesktop`
- **便携位置**：程序目录下的 `Desktop` 文件夹（注意目录名是 `Desktop`，不是 `Data`）

也可以显式指定：`LanMountainDesktop.Launcher.exe --data-root <路径>`（宿主侧也可用环境变量 `LMD_DATA_ROOT`）。

## 目录结构

### 安装根目录

```
安装根目录/
├── LanMountainDesktop.Launcher.exe        # 启动器：唯一入口
├── LanMountainDesktop.AirAppRuntime.exe   # AirApp 运行时（启动器预启动）
├── LanDesktopPLONDS.installer.exe         # 在线安装器 / 维护程序（同一 exe）
├── app-{version}-{index}/                 # 每个版本一个部署目录
│   ├── .current                           # 当前活动部署标记
│   ├── LanMountainDesktop.exe             # 主程序
│   └── ...
├── .Launcher/                             # 启动器数据
│   ├── state/                             # OOBE 状态
│   ├── snapshots/                         # 更新快照
│   ├── update/                            # 下载缓存与公钥
│   └── logs/
└── unins000.exe                           # Inno Setup 卸载程序
```

版本目录名是 `app-{version}-{index}`，index 用来避免重名；**版本号本身不能含 `-`**。

### 用户数据目录

系统位置模式下的 `%LOCALAPPDATA%\LanMountainDesktop\`：

| 路径 | 内容 |
|---|---|
| `Extensions/AirApps/` | 已安装轻应用（`.laapp`）与解包缓存 |
| `Extensions/Components/` | JSON 组件扩展 |
| `AirAppMarket/` | 市场索引缓存、下载、`SharedContracts/` |
| `Whiteboards/`、`Wallpapers/` | 白板笔记、壁纸 |
| `settings.json`、`launcher-settings.json`、`airapp-settings.json` | 各级设置 |
| `component-state.db`（SQLite） | 组件实例设置与桌面网格布局 |
| `desktop_panel_layout.json` | Windows 桌面板布局 |

**日志不在数据根**：宿主日志写在**程序目录下的 `log/`**（不可写时回退），文件名形如 `app-20261114.log`。

实际占用可以看宿主的「设置 → 存储」页（按分类统计，分类定义见 `DataStorageService`）。

## 启动与命令行

### 正常启动

双击 `LanMountainDesktop.Launcher.exe`，或从开始菜单启动。

### 命令行接口

**启动器没有 `--version`、`--help`、`--reset-oobe` 这类开关**，也没有"启动到指定版本"的参数——版本由启动器自己按部署目录选择。

真实可用的命令与选项：

| 命令 | 用途 |
|---|---|
| `launch`（默认） | 正常启动 |
| `preview-splash` / `preview-error` / `preview-oobe` / `preview-debug` | GUI 预览 |
| `plugin install` | 安装轻应用包（**必须带参数**，见下） |
| `plugin update` | 应用轻应用升级队列（**必须带参数**） |
| `desktop exit` | 请求宿主退出 |

| 选项 | 说明 |
|---|---|
| `--data-root <路径>` | 指定数据根 |
| `--app-root <路径>` | 指定程序根 |
| `--debug`、`--show-loading-details` | 调试与启动详情 |
| `--launch-source`、`--restart-presentation` | 启动来源与重启呈现（宿主↔启动器协议） |
| `--source <包路径>`、`--plugins-dir <目录>` | `plugin install` 用 |
| `--result <文件>` | 把结果写成 JSON |

```powershell
# 安装一个轻应用包（两个参数都是必需的）
.\LanMountainDesktop.Launcher.exe plugin install --source C:\path\MyApp.laapp --plugins-dir "$env:LOCALAPPDATA\LanMountainDesktop\Extensions\AirApps"

# 应用待升级队列
.\LanMountainDesktop.Launcher.exe plugin update --plugins-dir "$env:LOCALAPPDATA\LanMountainDesktop\Extensions\AirApps"
```

参数解析支持 `--k=v`、`--k v` 与裸开关三种写法。

## 验证安装

启动后应当看到：

1. **托盘图标** —— 阑山桌面常驻托盘
2. **主窗口** —— 从托盘打开
3. **桌面组件** —— 从组件库拖到桌面网格（默认不一定有组件）

### 检查日志

```powershell
# 程序目录下的 log/
Get-ChildItem .\log
Get-Content .\log\app-*.log -Tail 50
```

### 检查版本与更新状态

托盘 → 设置 → 关于 / 更新。

## 常见问题

### 安装失败

1. 确认 Windows 版本 ≥ Windows 10 1809
2. **以管理员身份运行**（安装包需要提权）
3. 检查磁盘空间
4. 查看安装日志：`%TEMP%\LanMountainDesktop-Setup.log`

> 安装包当前**没有 Authenticode 签名**（CI 里没有签名步骤），所以 Windows 会提示"未知发布者"。这是现状，不是下载损坏。

### 启动失败

1. 先看 `log/app-*.log` 的最新一条
2. 尝试以管理员身份运行
3. 检查是否有残留的 `.partial` / `.destroy` 目录干扰版本选择（见 [启动器系统](../04-架构与实现/02-启动器系统.md)）

### OOBE 反复出现

删除状态文件后重启：

```powershell
Remove-Item -Path "$env:LOCALAPPDATA\LanMountainDesktop\Launcher\state\oobe-state.json" -Force
```

> 注意路径是 `Launcher\state`。`.launcher`（小写、带点）是旧版兼容读取目录，删除它不会重置当前状态。

### 桌面看不到组件

桌面网格的组件是用户自己添加的：从组件库拖到桌面网格。若组件库为空，检查 `Extensions/AirApps` 下是否有已安装轻应用，以及它的加载是否失败（日志里有 `AirAppRuntime` 类别）。

## 卸载

### 用系统卸载

设置 → 应用 → 已安装的应用 → LanMountainDesktop → 卸载。

或直接运行安装根目录的 `unins000.exe`。

### 清理残留

卸载不会删用户数据：

```powershell
Remove-Item -Path "$env:LOCALAPPDATA\LanMountainDesktop" -Recurse -Force
```

## 更新

### 自动更新

1. 宿主在设置页触发检查（拉取 `PLONDS.json` 清单）
2. 有新版则下载并**暂存**，提示需要重启
3. 重启后由启动器切到新部署目录

更新是**目录级切换**：新版本写进新的 `app-{version}-{index}`，用 `.current` 标记切换。失败时旧目录仍在。

> **"增量只下载变更文件"要打折扣**：宿主路径在清单基线与当前版本匹配时才用增量包，否则走完整包；安装器那条路径即使叫"增量"也仍会下载完整 zip。详见 [增量更新实现](../05-更新与发布/02-增量更新实现.md)。

### 更新频道

- **Stable**：只接收 `channel = stable`
- **Preview**：接收 `stable` + `preview`

```
设置 → 更新 → 更新频道 → 选择频道
```
