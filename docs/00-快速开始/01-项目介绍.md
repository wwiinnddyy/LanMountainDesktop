# 项目介绍

## 什么是阑山桌面

**LanMountainDesktop（阑山桌面）** 是一个基于 .NET 和 Avalonia UI 的模块化桌面定制平台，旨在为用户提供高度可定制的桌面体验。

### 核心特性

#### 🧩 轻应用系统
- **桌面组件** - 在宿主进程内渲染，可放到桌面网格
- **窗口轻应用** - 由独立 `AirAppHost` 进程承载，与桌面崩溃隔离
- **轻应用 SDK** - 完整的轻应用开发工具包
- **轻应用市场** - 应用内轻应用浏览和安装
- **预留（未实现）** - 清单里的 `isolated-background` / `isolated-window` 只通过校验，不改变加载行为

#### 🎨 桌面组件（Widget）
- **可视化编辑** - 拖拽式布局编辑
- **多种组件** - 时钟、天气、日历、倒计时等
- **自定义组件** - 通过轻应用扩展新组件
- **主题支持** - 亮色/暗色模式自适应

#### 🚀 Air APP 系统
- **独立应用** - 在桌面环境中运行的独立窗口应用
- **生命周期管理** - 统一的应用启动、激活和清理
- **窗口模式** - 标准、无边框、全屏、工具窗口
- **IPC 通信** - 与桌面宿主的双向通信

#### ⚙️ 设置系统
- **分域管理** - 按功能模块组织设置
- **持久化** - 自动保存到本地
- **轻应用集成** - 轻应用可注册自己的设置页

#### 🔄 更新系统
- **文件级增量** - 增量包只含变更文件（动作仅 add/replace/reuse/delete），且要求清单基线与当前版本一致，否则走完整包
- **目录级原子切换** - 新版本写进独立的 `app-{version}-{index}` 目录，用 `.current` 标记切换；失败时旧目录仍在，不覆写现场
- **多版本共存** - 启动器按 `.current`、其次版本号降序选择；旧版本由清理阶段回收
- **完整性校验** - 主流程校验清单 checksums 与落地文件哈希（**不是** RSA 签名验签）

## 技术架构

### 核心技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| .NET | 10.0 | 应用框架 |
| Avalonia UI | 12.x | 跨平台 UI 框架 |
| FluentAvaloniaUI | 3.0 | Fluent Design 控件 |
| CommunityToolkit.Mvvm | 8.x | MVVM 框架 |
| PLONDS | 自研 | 应用增量更新与分发系统 |
| dotnetCampus.Ipc | 最新 | 进程间通信 |

### 项目结构

```
LanMountainDesktop/
├── desktop/LanMountainDesktop/                   # 主桌面宿主应用
├── desktop/LanMountainDesktop.Launcher/          # 启动器（OOBE、Splash、版本管理）
├── airapp/LanMountainDesktop.AirAppRuntime/      # Air APP 运行时容器
├── airapp/LanMountainDesktop.AirAppHost/         # Air APP 渲染进程
├── airapp/LanMountainDesktop.AirAppSdk/          # 轻应用 SDK（接口、清单、外观与设置契约）
├── core/LanMountainDesktop.Core/                 # 共享契约、IPC 与轻应用打包
├── platform/LanMountainDesktop.Platform/         # 平台差异层
├── mobile/                                       # 移动端壳（不参与桌面构建）
└── install/LanDesktopPLONDS.installer/           # 在线安装器
```

### 启动流程

```
用户启动 Launcher.exe
    ↓
Splash 先创建并显示
    ↓
启动管线：清理旧部署 → 探测已有宿主（命中则激活并结束）
    ↓
需要时跑 OOBE（临时隐藏 Splash，完成后再显示）
    ↓
预启动 AirAppRuntime（框架依赖 JIT 进程）
    ↓
扫描 app-* 目录，选最佳版本（要求目录内有主程序）
    ↓
启动 app-{version}-{index}/LanMountainDesktop.exe
    ↓
宿主初始化：日志、设置、主题、语言 → 外壳、托盘、主窗口
    ↓
后台加载轻应用、注册组件（不阻塞桌面可见）
    ↓
桌面就绪；启动器交接 Runtime 后退出
```

## 应用场景

### 个人用户
- **桌面定制** - 打造个性化的桌面环境
- **效率工具** - 快速访问常用功能和信息
- **信息聚合** - 在桌面上展示天气、日历、待办等

### 开发者
- **轻应用开发** - 为桌面扩展新功能
- **Air APP 开发** - 创建独立的桌面应用
- **组件开发** - 设计自定义桌面组件

### 企业用户
- **定制部署** - 企业专用的桌面环境
- **信息看板** - 展示企业数据和通知
- **工作流集成** - 集成企业工作流工具

## 版本与支持

### 当前版本
- **稳定版**: 查看 [GitHub Releases](https://github.com/wwiinnddyy/LanMountainDesktop/releases)
- **预览版**: 通过更新频道切换到 Preview

### 平台支持
- ✅ **Windows 10/11** - 完整支持
- 🚧 **Linux** - 计划支持
- 🚧 **macOS** - 计划支持

### 系统要求
- **操作系统**: Windows 10 1809 或更高版本
- **.NET Runtime**: 自动包含，无需单独安装
- **内存**: 建议 4GB 或更高
- **磁盘**: 安装需要约 200MB 空间

## 开发理念

### 模块化设计
所有功能通过轻应用和组件实现，核心保持精简。

### 开放生态
鼓励社区开发轻应用和组件，共建生态系统。

### 稳定可靠
原子化更新、版本回退、进程隔离等机制保证系统稳定。

### 性能优先
增量更新、延迟加载、异步渲染等优化确保流畅体验。

## 开源协议

仓库根目录目前没有统一 LICENSE 文件，各项目许可证以各自 `csproj` 为准，例如：

- `airapp/LanMountainDesktop.AirAppSdk` — MIT
- `core/LanMountainDesktop.Core` — LGPL-3.0-or-later

分发或二次开发前请按你实际使用的项目逐一确认。
